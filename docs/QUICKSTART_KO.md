# 한국어 시작 안내

이 저장소는 제안서의 정상 이미지 기반 이상 탐지 프로젝트를 시작하기 위한 실행 가능한 초안입니다. 실제 데이터셋 학습이나 성능 검증이 끝난 결과물은 아닙니다.

## 먼저 할 일

1. README의 설치 명령으로 환경을 만듭니다.
2. `Quick pipeline check` 명령을 순서대로 실행해 전체 흐름을 확인합니다.
3. 팀에서 데이터셋과 제품 카테고리를 확정합니다. MVTec AD는 후보이며 최종 선택이 아닙니다.
4. 실제 데이터 경로를 지정해 prepare, train, evaluate를 실행합니다.
5. Streamlit 데모에서 학습한 체크포인트 경로를 입력하고 같은 제품 종류의 이미지를 업로드합니다.

## 구현된 것

- 정상 학습 데이터와 정상 검증 데이터의 재현 가능한 분리
- 오토인코더의 복원 오차와 CNN 특징 거리 기반 이상 점수
- 검증 데이터만으로 점수 스케일과 판단 기준 설정
- 두 모델 및 앙상블의 성능 비교와 이미지별 결과 저장
- 이미지 업로드, 상대 히트맵, 사람의 검토 기록
- 기본 테스트와 GitHub Actions 자동 검사

`--offline-smoke` 옵션은 무작위 CNN 가중치를 사용합니다. 테스트가 잘 연결됐는지 확인하는 용도이며 보고서 성능 결과로 사용하면 안 됩니다. 실제 학습 명령에서는 이 옵션을 빼야 합니다.

## 팀이 결정할 것

데이터셋, 카테고리, 실험 횟수, 담당자, 공개 범위와 코드 라이선스는 아직 확정되지 않았습니다. 초안 기본값은 이미지 128×128, 학습 10 epoch, 검증 20%, 앙상블 50:50입니다. 문서에 확정된 조건과 편의상 정한 구현 기본값을 구분했습니다.

점수는 불량 확률이 아닙니다. 히트맵의 빨간색은 해당 이미지에서 상대적으로 의심스러운 위치를 의미합니다. 테스트 결과를 보고 임계값을 다시 맞추면 최종 성능을 과대평가할 수 있으므로 별도 개발 데이터가 필요합니다.

학번, 제안서 원본, 원본 데이터 및 모델 파일은 저장소에 올리지 않습니다. 데이터와 결과는 로컬의 data, artifacts, reports 폴더에 저장합니다.
